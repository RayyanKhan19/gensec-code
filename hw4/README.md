# Homework 4: Study Planner

**Author:** Rayyan Khan (`khanr2024`)

This project will become a Study Planner agent that combines a custom
study-planning MCP server with the official filesystem MCP server. The custom
server will provide study-planning tools, while the filesystem server will let
the agent work with study materials stored as files.

The application has not been implemented yet. `agent.py` and `mcp-server.py`
are initial scaffolds.
